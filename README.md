# 粒粒皆辛苦 / Every Grain Earned

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3831389006)

[English README](README.en.md) · [Steam 工坊中文介绍](WORKSHOP.zh.txt) · [English Workshop description](WORKSHOP.en.txt)

《饥荒联机版》农耕 Mod。管理水源、土壤盐分、低温和病害，保护耕地并培养巨大作物。以下数值按标准难度和每游戏日 480 秒计算。

## 水与土壤

- 浇水和降雨先补土壤湿度，超过上限 100 的水进入地表积水池，上限 300。液态积水可以回补土壤，回补量从积水扣除。
- 水面保持半透明，按积水量分为四档。大于 0 时显示浅湿土色，达到 100、170、240 时依次转为浅青、蓝色和深蓝。
- 夏季露天的蒸发按作物耗水调整，目标是让一台完整覆盖的洒水器接近供需平衡。巨树树冠下自然失水较少。实际结果受天气、作物、覆盖程度和洒水器重叠影响。
- 冬季地表积水达到 100 时冻结，冻坏田里的作物。冰面打滑且无法耕种，液态积水的毁田计时在冻结期间暂停。

## 盐害与毁田

- 未淡化海水每 100 水带入 50 盐。土壤盐量上限为 300。达到 50、120、200 时显示三档白斑，素材对应干田用水壶浇 2、3、4 次的湿痕，旋转 90° 显示。盐量达到 120 时作物承受盐分压力。
- 盐量达到 200 后开始累计盐害毁田进度。低于 200 时进度以两倍速度回退。淡水和雨水可提供洗盐用的水，盐要由沙袋实际排水带走。
- 未冻结的积水达到 100 时累计水涝损伤，标准难度累计 3 天毁田。水量低于 100 后进度回退，排干后清除该预警进度。
- 夏季空田也会干旱。连续无地表水且土壤干燥，先宽限 1 天，再累计 1 天损伤。重新湿润会清除干旱进度。
- 三种毁田共用两档裂纹预警，约在进度 10% 和 40% 出现。一档为二档尺寸的 50%。正式毁田和休耕期间的裂纹缩至原素材显示尺寸的 80%，原因分别用白色、沼泽色、干涸湖底色斑块表示积盐、积水、干旱。
- 正式毁田后保留田面并锁定耕种 **4 天**。休耕结束后裂纹消失，田格恢复开垦前的地皮，需要重新开垦。旧毁田的剩余时间按原有恢复进度换算。
- 一台洒水器连续用未淡化海水完整灌溉一格，从零积盐到重度约 2.1 天，再过约 3 天毁田。该估算假定没有排水治理。

## 作物与农药

- 原版种子至中株阶段的基础生长时长加倍。已被 Shadow World 加过倍率的定义沿用其倍率。作物可以反季生长，但结果时仍不应季就直接枯萎，无法收获果实。枯萎后不会自动再生。持续低温也可使作物腐烂。
- 生长期每天和进入各生长阶段时各独立判定一次随机发病，每次 **2%**。判定记录随作物存档。长期浸泡和邻株传染也会引发疾病。
- 生长中的作物超过自身耐涝水位后停长，浸泡约 0.8～1.4 天可发病。病株停长，约 2 天未治会腐烂。原版旧疾病组件约每 1.5～2.5 天尝试传染 4 游戏单位内的一株植物，休眠时推迟。
- 装备并投掷农药。药雾约持续 80 秒，每 3 秒治疗一次，半径约 5.66 游戏单位。投在四格田交点可覆盖 2×2 农田的四角。病株田格积水须低于 100。农药可治疗病株并保留生长进度，腐烂的作物无法治愈。

## 设备与配方

| 物品 | 配方 | 用法 |
|---|---|---|
| 自动洒水器 | 齿轮 ×2、金块 ×4、木板 ×2 | 从附近水源灌溉，优先取淡水 |
| 海水淡化洒水器 | 齿轮 ×2、蓝宝石 ×4、活木 ×2 | 蓝宝石先消耗，再提供半天淡化时间。启迪碎片可持续淡化 |
| 布 | 蜘蛛丝 ×3 | 用于制作沙袋 |
| 排水沙袋 ×4 | 布 ×2、绳子 ×2、石头 ×8 | 吸取积水并带走盐分 |
| 农药 | 硝石 ×3、格罗姆黏液 ×1、空瓶 ×1 | 投掷后治疗范围内的病株 |

洒水器需在水源附近约 20 单位内建造。可取海水、池塘水、夏季绿洲水及支持的洞穴水源。运行中的洒水器只有供应淡水或正在淡化时才能给水壶装水。

沙袋优先排脚下的田，再协助周围田格。默认排水半径 4，每袋最多吸 300 水，每排 100 水最多带走 100 盐，实际吸盐量取决于盐浓度。吸满后停止排水，继续浸泡会损坏。可检查已吸水量、吸盐量及袋内平均盐水比。

## 联机与配置

主机和所有玩家都需要安装同一版本。可在 Mod 配置中分别切换积水、干旱、疾病、寒害、应季结果和盐害，调整环境恶化速度和沙袋范围。游戏内名称和提示支持中英文，配置标签随游戏语言切换。由专用服务器生成的动态检查文本随服务器语言显示。

本说明按当前本地代码整理。行为测试使用 `tests/run_tests.py`，游戏内画面和联机提示可在测试世界确认。
